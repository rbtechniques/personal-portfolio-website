# 🌐 Personal Developer Portfolio

A simple yet modern, responsive **Personal Developer Portfolio Website** built using HTML and CSS.

This project brings my personal bio, technical skills, and GitHub projects together in one place, making it easier for visitors to explore my developer journey and work.

## ✨ Features

- **Personal Introduction:** A dedicated hero section introducing me.
- **About Me:** Information about my background and interests.
- **Skills Section:** Showcases my technical skills and technologies.
- **Projects Showcase:** Displays selected projects with descriptions and GitHub links.
- **Contact Section:** Provides links to connect with me.
- **Responsive Design:** Works across desktop, tablet, and mobile devices.
- **Modern UI:** Dark theme with gradient accents, hover effects, and smooth scrolling.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts
- Flexbox
- CSS Grid
- CSS Media Queries

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bashgit
git clone https://github.com/YOUR-USERNAME/Personal-Developer-Portfolio.
```

**2. Navigate to the project folder**

```bash
cd Personal-Developer-Portfolio
```

**3. Open the website**

Open `index.html` in your preferred web browser.

No additional installation or dependencies are required.

## 🎨 Customization

You can personalize the portfolio by:

- Updating the name and introduction in `index.html`.
- Adding your own GitHub repositories.
- Changing the skills and technologies displayed.
- Updating your social media and contact links.
- Modifying colors, fonts, and layouts in `style.css`.

## 🎯 Project Objective

The main objective of this project is to create a centralized online presence where I can showcase my skills, introduce myself, and display my development projects.

It also helped me practice the fundamentals of HTML and CSS, including webpage structuring, styling, responsive layouts, and modern UI design.
